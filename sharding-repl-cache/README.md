
# Общая последовательность
Работайте с утилитой make
1) Запускайте все сервисы (команда start)
2) Инициализируйте Сервер Конфига, Шарды и Сервер Роутер от MongoDB (команда init)
   Запускайте инициализацию поэтапно:
   > make init_mongodb-configs
   > make init_replica_shard1
   > make init_replica_shard2
   > make init_mongos-router
   > make init_db
   Если на какой-то команде будет ошибка, просто запустите ее еще раз через некоторое время и все заработает
3) Добавьте новые тестовые данные (команда add-mongodb)
4) Проверьте статистику распределения документов по шардам (команда stats-shards)
5) Проверяем статус всех сервисов, включая кеширование (команда status)

Также доступен сервис: http://localhost:8090/docs
